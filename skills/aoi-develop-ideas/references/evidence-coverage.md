# Claim-level evidence and dependency coverage

Use this check before scoring and freezing. A source manifest inventories documents;
the evidence ledger inventories material claims. A single issuer operating observation
cannot substantiate every scoring dimension merely because it concerns the same company.

For each idea, make a compact `dependency-coverage.json` or table whose rows name the
specific field/claim, required source role, actual evidence IDs and locator, and support
status/gap. Every cited ID must resolve to a contract-complete claim record. Use unknown
clocks explicitly; do not create fictitious precision to fill required fields.

| Material field | Evidence to record and bind when used |
|---|---|
| Seed thesis / defined success event | Author's actual thesis/proposed condition, with article section and opinion/definition role. An operational thesis does not establish market consensus mispricing. |
| Catalyst / earliest check / resolution | Exact author/issuer timing passage, including its precision and conditionality. A hypothetical entry date or AOI review deadline has a separate assumption record. |
| Falsifier / strongest countercase | Author-proposed thresholds and issuer/regulator/customer facts as separate claim records, with exact source roles and whether the condition has actually occurred. |
| Evidence-quality score | Relevant material primary/counterevidence, source independence and author incentive/disclosure records; include reliability/strength reasoning. |
| Mechanism score | Source-derived causal thesis plus supporting/challenging operational claims, not just a repeated source list. |
| Valuation score / return forecast | Price reference, economic-to-valuation anchors and model assumptions. Assumption records are not verified financial anchors; missing bridges remain explicit and unscored. |
| Catalyst score | The particular timing/feasibility evidence it relies on; issuer operating numbers alone do not substantiate an author's quarterly-check window. |
| Downside score | Specific concentration, cancellation, financing or other adverse facts/conditions and modeled stresses; distinguish observed facts from proposed triggers. |
| Implementation score | Instrument identity, price timestamp/session/adjustment, currency, liquidity/spread and cost records used by the rationale. Do not cite only operating/customer evidence for a claimed price/cost check. |
| TLDR ratings | Provider/type/value/scale/as-of and actual panel/author source, labeled model or analyst opinion. Missing categories have explicit gaps/next checks. |
| Model outputs / later entry | Configured assumptions, duration, distributions/cost/FX inputs, trigger/no-fill conditions and calculation locators; separate arithmetic from empirical validation. |

Include both supporting and opposing records, with direction, explained strength,
reliability, independence, affected assumption and superseded/retracted state as required
by the contract. An absent publication/event time may be unknown with rationale, not
omitted. Source-specific authorship/publisher and original retrieval clocks still matter.

When assigning a dimension, cite only the claim IDs that actually support that dimension
and explain the dependency. Do not mechanically paste all idea evidence IDs into all six
dimensions. If a needed kind of input is missing, record the gap and its effect on the
score/forecast. Regenerate score authority, snapshots and summaries from that map. Freeze
this coverage check with the output for independent evaluation; it is not itself a pass.
