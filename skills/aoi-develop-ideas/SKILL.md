# aoi-develop-ideas

Harvest and triage new ideas for AOI.

1. Read [the research contract](../../docs/research-contract.md). Load the configured universe, constraints, existing ideas, and prior learnings. If scope is absent, state an exploratory listed-equity scope and avoid personal allocation recommendations.
2. Search quality analysis such as accessible Seeking Alpha articles, specialist research, earnings transcripts, filings, and industry data. Record the discovery window, source quality, candidate leads, duplicates, and reasons for rejection. Do not force a quota when no defensible idea emerges.
3. Turn promising leads into falsifiable theses: explain the causal mechanism, what the market may be missing, catalyst, horizon, strongest counter-thesis, disconfirming tests, and target equity exposure. Validate material claims using original sources and seek contrary evidence.
4. Create an idea snapshot with the contract's evidence ledger, defined success event, likelihood, scenario returns for entry today and later, risks, and next checks. Separate attractive business from attractive entry valuation. Do not promote an incomplete candidate to a fully researched active idea.
5. Deliver a ranked shortlist with ranking rationale, rejected-candidate log, source coverage, data gaps, and snapshot paths. Request evaluation with `aoi-evaluate-idea-development` before treating the output as vetted.
